IntiHA v0.2.3 - Bond safe-stop hotfix

Apply the contents of this ZIP at the ROOT of your GitHub repository
https://github.com/s2n2/IntiHA (overwrite matching files).

Or use the separate IntiHA-v0.2.3.patch from your repository root:

  git apply IntiHA-v0.2.3.patch
  git add -A
  git commit -m "Fix We-Vibe stopped-state initialization"
  git push

The v0.2.3 release number must be visible in the HA app store before
installing the updated engine. Refresh the app store repository, then
rebuild/reinstall IntiHA Engine as appropriate. Restart the engine app.
The HACS integration metadata is also updated to v0.2.3.

The fix is restricted to recognized classic We-Vibe protocol devices with
the known control characteristic. It does NOT bypass safety checks for
unknown devices or prove real-Bond compatibility. See Last error if it
still refuses control. Rust builds and real BLE testing are outstanding.
