IntiHA v0.2.2 GitHub patch (based on v0.2.1)

Option 1: use the .patch file
  git apply IntiHA-v0.2.2.patch
  git add -A
  git commit -m "Fix Docker install without host-side licenses directory"
  git push

Option 2: copy the changed files from this ZIP into the same paths
of your s2n2/IntiHA GitHub checkout, overwriting existing files,
then commit and push. Do not upload ZIP itself as an app store file.

IMPORTANT: in engine/Dockerfile there must NOT be a line starting
  COPY licenses
Instead the Dockerfile gathers third-party licences from pinned
Rust dependencies in the builder stage.

In Home Assistant: Settings > Apps > App store > 3-dot menu > Check for updates
(or reload repositories), then try installing IntiHA Engine v0.2.2.
The GitHub Actions app-image build needs to pass on your repository.

The package was statically checked and its licence-collection script was
simulated. No full Docker build has been executed in this environment.
