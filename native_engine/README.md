# IntiHA Native Engine

Experimental native-reference HA app for IntiHA 0.3.0b1. It builds and starts the
unmodified published Intiface Engine 4.1.0. It does not run the former custom
IntiHA Rust bridge. See DOCS.md before installation.

**Uses real host Bluetooth through BlueZ/D-Bus. Does not use ESPHome proxies.**
